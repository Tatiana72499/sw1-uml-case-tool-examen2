# Proyecto Primer Parcial - Ingeniería de Software 1

Herramienta CASE colaborativa orientada al diseño de diagramas de clases UML,
asistida mediante Inteligencia Artificial y con capacidad de generación de
backend Spring Boot.

## Objetivo

Permitir crear, modificar, importar y colaborar sobre diagramas UML de clases,
utilizando diferentes mecanismos de entrada:

- Edición manual
- Inteligencia Artificial mediante texto
- Comandos por voz
- Fotografía de diagramas
- Importación XMI desde Enterprise Architect

A partir del modelo UML, el sistema podrá generar un backend basado en:

- Spring Boot
- Maven
- JPA / Hibernate
- PostgreSQL
- Entity
- Repository
- Service
- Controller
- DTO cuando corresponda

## Estructura

```text
backend/   Backend de la herramienta CASE
frontend/  Aplicación web
docs/      Documentación académica y técnica
tests/     Pruebas generales
```
